# 🌦️ Weather App

A modern, responsive weather application that provides real-time weather information for any city using a Weather API. The application features a clean user interface and delivers accurate weather updates, including temperature, humidity, wind speed, and weather conditions.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Ekta8527/WEATHER-APP.git
```

Open the project folder:

```bash
cd WEATHER-APP
```

Run the application by opening:

```text
index.html
```

in your preferred web browser.
